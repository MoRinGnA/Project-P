# AI 여행플래너 Project-P (임시)

다중 사용자가 AI를 통해 빠르고 편리하게 여행을 계획할 수 있는 웹 플래너

처음 시작 시, AI에게 원하는 장소, 테마, 예상 예산, 기간을 입력할 수 있는 칸과

처음부터 본인이 직접 일정을 추가하고 싶다면 " 혼자서 시작하기 " 버튼을,

다른 사용자와 함께 여행을 계획하고 싶다면 "링크 생성하기 " 버튼을 클릭하여 일정을 추가할 수 있습니다.

사용자는 언제든지 링크를 복사하여 다른 사용자에게 전달한다면 언제든지 같이 일정을 공유할 수 있습니다.

AI에게 여행의 정보를 입력하고 AI 자동 생성으로 시작하기 버튼을 누르게되면 버튼에 로딩 텍스트가 뜨며

일정이 생성됩니다. 해당 일정은 최대한 사용자의 입력에 맞는 장소, 시간, 예산에 맞게 구현되었으며,

사용자는 각각의 날짜마다 어느정도의 예산이 소모되고, 총 얼마가 소모되는지 한눈에 확인할 수 있습니다.

또한 해당 일정과, 일차를 우클릭을 통해 삭제 및 편집할 수 있으며 일정을 클릭하여 AI가 어떤 장소를 추천하였고 

어느 위치에 있는지 알맞은 지도 서비스를 통해 확인하실 수 있습니다. 

또한 일정의 순서를 변경하고 싶다면 간단하게 일정의 오른쪽 ☰를 드래그 하여 순서를 변경하실 수 있습니다.

장소를 추가하기 위해서는 원하는 지도 서비스를 클릭하고 장소를 입력하여 

원하는 장소를 선택하고, 일정에 추가 버튼을 클릭하면 

어느 날에 해당 장소를 방문할건지, 어느 시간에 방문할건지를 선택하실 수 있습니다.

해당 날짜는 일정 탭과 연동되어 자연스럽게 장소를 일정에 추가하실 수 있습니다.


---
**로드맵**

1단계: 서비스 기획 및 MVP 구현 (1~4주차)

* 개발 환경 세팅 (Vite, React, Tailwind CSS) 및 Git 형상 관리 체계 구축
* 여행 일정 UI 기본 레이아웃 설계 및 dnd-kit을 이용한 드래그 앤 드롭 기초 구현
* 카카오맵/구글맵 API 연동 및 지도 서비스 모듈화
* Gemini AI API 통합 및 일정 자동 생성 기능 구현

2단계: 실시간 동기화 아키텍처 구축 (5~8주차)

* Node.js/Express 서버 구축 및 Socket.io를 활용한 양방향 통신 환경 조성
* 실시간 커서 공유 시스템 및 지도 엔진 간 DOM 분리/충돌 방지 아키텍처 설계
* 데이터 동기화 로직 최적화 및 드래그 앤 드롭 정밀 제어 구현
* 컴포넌트 단위 기능 분리 및 코드 리팩토링

3단계: UX 고도화 및 세션 관리 시스템 (9~12주차)

* 일정별 예산 합산 로직 및 실시간 예산바 UI 구현
* UUID 기반 독립 세션 격리 및 초대 링크 복사/공유 시스템 구축
* AI 프롬프트 튜닝 및 정규식 기반 비용 산출 로직 고도화
* 브라우저 이탈 방지 경고 및 라우팅 상태 분리 등 UX 안정화 작업

4단계: 인프라 안정화 및 서비스 완성 (13~14주차)

* Vercel에서 우분투 미니 PC 서버로 인프라 환경 이전 및 패키지 빌드
* Tailscale을 활용한 외부 접속 터널링 및 다중 네트워크 대역 호스트 바인딩 구현
* 서버 배포 환경의 DNS 해석 오류(EAI_AGAIN) 해결 및 네트워크 인터페이스 최적화
* CRDT 기반 분수 인덱싱 도입을 통한 드래그 앤 드롭 정렬 알고리즘 논리화 및 최종 검증

**[1. AI가 구현]**

* Gemini AI API 통합 및 여행 일정 자동 생성 로직 기초 구현
* 구글맵/카카오맵 API 연동 및 초기 지도 탭 서비스 구성
* dnd-kit 라이브러리를 활용한 타임라인 드래그 앤 드롭 기초 기능
* AI 프롬프트 초기 튜닝 및 JSON 구조 기반 데이터 파싱 로직
* React-Router를 통한 화면 라우팅 기초 및 View 상태 분리
* UUID 기반의 초기 Room ID 생성 및 초대 링크 복사 로직 구현
* 브라우저 경고창 및 다중 접속 환경의 초기 세션 격리 로직

**[2. AI가 구현한 것을 내가 수정하여 커밋]**

* 컴포넌트 구조화 및 파일 분리 (App.jsx 중심 스파게티 코드 개선)
* 지도 엔진 간 DOM 충돌 방지 및 탭 전환 시 오류 해결
* 쓰레기통 로직 개선 및 드래그 앤 드롭 드래그 핸들 최적화
* 사용자 경험(UX) 개선: 모달 레이아웃 정립, 일정 클릭 시 지도 이동, UI/UX 통일
* AI 프롬프트 고도화 및 정규식 기반 예산 산출 로직 수정
* 실시간 데이터 동기화 과정에서 발생하는 지도 API 레이어 버그 수정
* CSS 레이아웃 재정립 및 불필요한 로컬 저장소 의존성 제거
* AI 대기 시간 중 순차 로딩 텍스트 UI 도입 및 가독성 향상

**[3. 내가 직접 구현]**

* Node.js/Express 서버 및 Socket.io 기반 양방향 실시간 동기화 아키텍처 설계
* CRDT(분수 인덱싱) 알고리즘 도입을 통한 타임라인 정렬 논리화 (드래그 앤 드롭 튕김 현상 완벽 해결)
* 서버 환경 보안 강화: API 키 환경 변수(.env) 관리 및 서버 사이드 프록시를 통한 키 유출 원천 차단
* 인프라 이전: Vercel에서 우분투 미니 PC 서버 환경으로 이전 및 빌드 시스템 구축
* 네트워크 인프라 최적화: Tailscale 기반 폐쇄망 터널링 구축 및 가상 IP/호스트 바인딩 구현
* 서버 안정화: 네트워크 장애 대응 DNS 설정 및 포트 충돌 자동 방지 스크립트(start.sh) 구축
* 다중 접속 세션 격리: Socket.join 시스템 이식 및 Room 기반 데이터 동기화 흐름 완비
* 성능 최적화: 지도 엔진 성능 개선 및 배포 환경 리소스 관리(가상 메모리 등) 설정
* 프로젝트 전체 로드맵 및 개발 과정 문서화, 지속적인 이슈 트래킹 관리
