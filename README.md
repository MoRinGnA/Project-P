# AI 여행플래너 Project-P (임시)

다중 사용자가 AI를 통해 빠르고 편리하게 여행을 계획할 수 있는 웹 플래너

처음 시작 시, AI에게 원하는 장소, 테마, 예상 예산, 기간을 입력할 수 있는 칸과

처음부터 본인이 직접 일정을 추가하고 싶다면 " 혼자서 시작하기 " 버튼을,

다른 사용자와 함께 여행을 계획하고 싶다면 "링크 생성하기 " 버튼을 클릭하여 일정을 추가할 수 있습니다.

사용자는 언제든지 링크를 복사하여 다른 사용자에게 전달한다면 언제든지 같이 일정을 공유할 수 있습니다.

AI에게 여행의 정보를 입력하고 AI 자동 생성으로 시작하기 버튼을 누르게되면 버튼에 로딩 텍스트가 뜨며

일정이 생성됩니다. 해당 일정은 최대한 사용자의 입력에 맞는 장소, 시간, 예산에 맞게 구현되었으며,

사용자는 각각의 날짜마다 어느정도의 예산이 소모되고, 총 얼마가 소모되는지 한눈에 확인할 수 있습니다.

또한 해당 일정과, 일차를 우클릭을 통해 삭제 및 편집할 수 있으며 일정을 클릭하여 AI가 어떤 장소를 추천하였고 

어느 위치에 있는지 알맞은 지도 서비스를 통해 확인하실 수 있습니다. 

또한 일정의 순서를 변경하고 싶다면 간단하게 일정의 오른쪽 ☰를 드래그 하여 순서를 변경하실 수 있습니다.

장소를 추가하기 위해서는 원하는 지도 서비스를 클릭하고 장소를 입력하여 

원하는 장소를 선택하고, 일정에 추가 버튼을 클릭하면 

어느 날에 해당 장소를 방문할건지, 어느 시간에 방문할건지를 선택하실 수 있습니다.

해당 날짜는 일정 탭과 연동되어 자연스럽게 장소를 일정에 추가하실 수 있습니다.
